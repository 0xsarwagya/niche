# Security Policy

## Supported versions

Niche is pre-1.0. Security fixes land on the latest release and `main`.

## Reporting a vulnerability

Please report vulnerabilities **privately**, not in public issues.

Use GitHub's private vulnerability reporting: open the repository's
**Security** tab and choose **Report a vulnerability**. We'll acknowledge the
report and keep you updated on the fix.

When you can, include: affected version, reproduction steps, and the impact.
